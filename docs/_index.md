Layup is a visual page builder plugin for Filament 5. It provides Divi-style editing with a 12-column responsive grid, breakpoint previews, undo/redo, and a searchable widget picker.

Every widget ships with a three-tab form (Content, Design, Advanced), full dark mode support, entrance animations, and responsive visibility controls. Includes content validation, revision history, page templates, and Tailwind safelist generation.
