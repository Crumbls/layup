Content widgets handle text, typography, data display, and structured content blocks. This is the largest widget category.

## Text and typography

| Widget | Type | Description |
|--------|------|-------------|
| Text | `text` | Rich text content via Filament's RichEditor |
| Rich Text | `rich-text` | Extended rich text editor |
| Heading | `heading` | Heading (h1-h6) with optional link |
| Animated Heading | `animated-heading` | Heading with entrance animation effects |
| Gradient Text | `gradient-text` | Text with CSS gradient coloring |
| Typewriter | `typewriter` | Typing animation effect on text |
| Text Columns | `text-columns` | Multi-column text layout |
| Blockquote | `blockquote` | Styled quotation block |

## Cards and boxes

| Widget | Type | Description |
|--------|------|-------------|
| Card | `card` | Content card with image, title, body, and link |
| Highlight Box | `highlight-box` | Emphasized content box with border or background |
| Icon Box | `icon-box` | Icon paired with heading and description |
| Blurb | `blurb` | Compact promotional block with icon and text |
| Alert | `alert` | Styled notification/alert message |
| Badge | `badge` | Small label/tag element |
| Flip Card | `flip-card` | Interactive card with front/back content |

## Lists and navigation

| Widget | Type | Description |
|--------|------|-------------|
| List | `list` | Ordered or unordered list |
| Icon List | `icon-list` | List items with custom icons |
| Feature List | `feature-list` | Feature items with icons and descriptions |
| Menu | `menu` | Navigation menu links |
| Breadcrumbs | `breadcrumbs` | Breadcrumb navigation trail |
| Table of Contents | `table-of-contents` | Auto-generated heading links |
